# Groq Cloud API Key Usage

This document explains how to create a Groq Cloud API Key and provides information about the application's content.

## How to Create a Groq Cloud API Key

1. Go to the **Groq Cloud Playground** page: [Groq Cloud Playground](https://console.groq.com/playground)
2. Locate and click on the **API Keys** section in the left menu.
3. If you don’t have an account, first **sign up**. If you already have an account, **log in**.
4. Click the **Create API Key** button.
5. Provide a name for the API Key. (You can choose any name you like.)
6. Make sure to **save your API Key**, as it will only be displayed once. If you lose it, you will need to create a new API Key.

> **Note:** Don’t forget to back up your API Key! If it gets lost, you won’t be able to retrieve the same key again.
